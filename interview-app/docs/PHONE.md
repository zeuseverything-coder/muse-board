# スマートフォン接続手順

1. PCとスマホを同じWi-Fi（同一LAN）に接続します。
2. PCでアプリを起動し、「面接準備」画面で企業プロファイルを選んで「セッション開始」を押します。
3. 表示されたQRコードをスマホのカメラで読み取ります（専用アプリのインストールは不要、ブラウザで開きます）。
4. スマホ側は自動的に「ライブ支援」画面が開き、PCと同じ質問・回答がリアルタイム表示されます。
5. 接続が切れた場合は自動で再接続され、直近の質問・回答は復元されます。
6. 面接が終わったらPC側で「セッション終了」を押してください。接続用トークンはその時点で無効化されます。

注意:
- 外部インターネットへの公開は行いません。必ず同一LAN内でのみ使用してください。
- iPhoneはSafari、AndroidはChromeでの利用を想定しています。
- スマホのブラウザからマイクを使う場合は、そのページのマイク許可が必要です（面接官音声の取得はPC側のループバックが本命です）。
