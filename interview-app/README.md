# リアルタイムAI面接支援アプリ

Web面接で面接官の質問をリアルタイムに文字起こしし、登録した職務経歴書・自己分析・想定問答・企業情報を参照して回答案（要点／回答例／補足／想定深掘り）をPCとスマートフォンに同期表示するアプリです。

- 完全ローカル動作・追加費用0円（有料API不使用、外部送信なし）
- 音声・個人情報は初期設定で保存しません（履歴保存は設定で任意に有効化）
- 模擬面接、およびAI利用の許可を得た面接でのみ使用してください

## クイックスタート（Windows）

1. Python 3.11+ をインストール
2. `scripts\setup_windows.bat` を実行（仮想環境・依存関係・Whisperモデルの事前取得まで自動）
3. （生成AIを使う場合）`docs\MODELS.md` の手順で Ollama とモデルを導入
4. `scripts\start_windows.bat` を実行 → ブラウザで http://localhost:8765 が開きます

## 使い方

1. **資料管理**: 職務経歴書・自己分析などを登録（貼り付け、または PDF/DOCX/TXT/MD/CSV/JSON 取り込み。CSVは「質問,回答」形式で想定問答として取り込まれます）
2. **想定問答**: 想定質問と登録回答を登録。意味検索で言い回しの違いにも対応します
3. **企業プロファイル**: 応募先ごとに求人情報・企業研究を管理（共通資料は全企業で再利用）
4. **面接準備**: プロファイルを選びセッション開始 → QRコードをスマホで読み取り接続
5. **ライブ支援**: 音声ソースを開始
   - PC内部音声（WASAPIループバック、Windows）: イヤホン使用時でも面接官の声を取得
   - PCマイク: 自分の声（自分の発言には回答生成しません）
   - ブラウザマイク: ページを開いた端末のマイクから取得
   - 手動入力: テキストを貼り付けて処理（判定あり／強制生成の2モード）
6. 質問と判定されると、登録回答があれば即時表示、なければローカルAIが資料を参照して生成し、要点から逐次表示されます

## 画面構成

ホーム／面接準備／資料管理／企業プロファイル／想定問答／ライブ支援／面接履歴／設定／接続・動作テスト。
ライブ支援では要点を最大表示、ライト/ダーク切替、文字サイズ調整、要点のみモード、認識の一時停止・再開、回答の再生成、質問の手動修正、接続状態表示に対応します。

## 構成

| 層 | 実装 |
|---|---|
| バックエンド | Python / FastAPI + WebSocket（`app/main.py`） |
| 音声取得 | 抽象化層 `app/audio_sources.py`（WASAPIループバック / マイク / ブラウザ / ファイル） |
| 音声認識 | faster-whisper（短区間分割＋重複除去＋エネルギーVAD、任意でSilero VAD） |
| 質問判定 | 日本語ヒューリスティクス `app/question_detector.py`（＋手動トリガー） |
| 意味検索 | sentence-transformers（任意）／文字n-gram TF-IDF＋概念正規化フォールバック |
| 回答生成 | Ollama（ローカルLLM、ストリーミング）／未接続時はモック生成に自動切替 |
| データ | SQLite（`data/app.db`） |
| 同期 | WebSocket（セッショントークン認証、再接続時はイベント再生で復元） |

## プライバシーと安全

- 音声データは保存しません。文字起こし・回答の履歴保存は設定で明示的に有効化した場合のみ
- 登録資料はローカル（SQLite）に保存。外部サービスへは一切送信しません
- LAN内のみで使用し、インターネットへは公開しません。セッション終了でトークン無効化
- 設定画面から全データの完全削除が可能
